# Launchpad (lpad)

Launchpad — полноэкранный лаунчер приложений, вдохновлённый macOS Launchpad. Приложение написано на Python и Qt и поддерживает Python 3.9–3.11.

## Возможности

- Автоматическое обнаружение `.desktop` файлов из `/usr/share/applications` и `~/.local/share/applications` (включая подпапки).
- Сетка ярлыков 5×7 с постраничной навигацией, перелистыванием по стрелкам, колесику мыши и кнопкам на экране.
- Поле поиска с автоматическим фокусом при запуске.
- Контекстное меню для скрытия приложений (сохранение в конфигурацию `~/.config/lpad/conf.json`).
- Настраиваемый фон: путь к изображению можно указать в конфигурации, иначе приложение попытается использовать обои рабочего стола или применит белый фон.
- Автоматический выбор цвета подписей в зависимости от яркости фона.
- Закрытие по `Esc`.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install .
```

Или для запуска без установки:

```bash
pip install -e .
```

## Запуск

После установки приложение доступно из командной строки:

```bash
launchpad
```

Либо напрямую из исходников:

```bash
python -m lpad
```

## Конфигурация

Файл `~/.config/lpad/conf.json` создаётся автоматически при первом запуске. Пример содержимого:

```json
{
  "background_image": "/path/to/wallpaper.jpg",
  "hidden_desktop_ids": ["org.gnome.Nautilus"]
}
```

- `background_image` — путь к изображению фона. Если поле пустое или файла не существует, используется системные обои (при наличии) или белый фон.
- `hidden_desktop_ids` — список идентификаторов `.desktop` файлов, скрытых через контекстное меню.

## Требования

- Python 3.9 или новее
- Qt 6 (пакет PySide6)
