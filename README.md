# lpad

Простое полноэкранное приложение-«ланчпад» для настольных окружений KDE. Оно
отображает сетку установленных приложений (системных и пользовательских) на
основе `.desktop`-файлов из каталогов `/usr/share/applications` и
`~/.local/share/applications`.

## Возможности

* Плиточная сетка 5×7 с пагинацией.
* Отображение иконок из темы рабочего стола.
* Запуск приложения по клику и мгновенное закрытие ланчпада.
* Переключение страниц кнопками, клавишами «влево/вправо» и колесиком мыши.
* Фон подхватывается из текущих настроек обоев KDE (есть запасной вариант).

## Запуск

```bash
python3 launchpad.py
```

Для работы требуется установленный PyQt5.
