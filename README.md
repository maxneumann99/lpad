# lpad

Простое полноэкранное приложение-«ланчпад» для настольных окружений KDE и других X11/Wayland-сред.
Оно отображает сетку установленных приложений (системных и пользовательских) на основе
`.desktop`-файлов из каталогов `/usr/share/applications` и `~/.local/share/applications`.

## Возможности

* Плиточная сетка 5×7 с пагинацией и навигацией мышью или клавиатурой.
* Отображение иконок из текущей темы, с резервным поиском по файловой системе.
* Поддержка пользовательских `.desktop`-файлов и мгновенное закрытие после запуска приложения.
* Демон `lpad-daemon.py`, принимающий команды через UNIX-сокет, и CLI `lpad-command.py`.
* Скрипт установки `install.py`, разворачивающий набор утилит в `~/.local/apps/lpad`.

## Требования

* Python 3.8+
* PyQt5

Установите PyQt5, например:

```bash
sudo pacman -S python-pyqt5          # Arch
sudo apt install python3-pyqt5       # Debian/Ubuntu
pip install pyqt5                    # Универсальный вариант
```

## Запуск напрямую

```bash
python3 launchpad.py
```

Для постоянного резидентного режима (используется демоном) предусмотрен флаг `--resident`,
который запускает процесс с управляющим UNIX-сокетом и скрывает окно до получения команды
показа.

## Установка в домашний каталог

1. Скопируйте файлы проекта в удобный каталог.
2. Выполните:

   ```bash
   python3 install.py
   ```

   Скрипт создаст `~/.local/apps/lpad/`, разместит там `launchpad.py`, `lpad-daemon.py`,
   `lpad-command.py` и вспомогательные ресурсы, а также добавит исполняемые врапперы в
   `~/.local/bin` (каталог будет создан при необходимости).

После установки убедитесь, что `~/.local/bin` присутствует в переменной окружения `PATH`.

## Управление демоном

Демон поддерживает «тёплый старт» — он заранее поднимает процесс `launchpad.py` в резидентном
режиме, прогревает окно вне экрана и по команде мгновенно показывает интерфейс. Благодаря
этому `lpad-command.py --open` только раскрывает уже готовое окно и укладывается в сотни
миллисекунд. Взаимодействовать с ним можно через
`lpad-command.py` (или просто `lpad-command` после установки):

```bash
python3 lpad-command.py --open     # Открыть окно ланчпада через демона
python3 lpad-command.py --start    # Запустить демон в текущей сессии (если он не запущен)
python3 lpad-command.py --enable   # Включить автозапуск демона при старте сессии
python3 lpad-command.py --disable  # Отключить автозапуск демона
```

Запуск демона вручную:

```bash
python3 lpad-daemon.py
```

Демон создаёт управляющий сокет `~/.local/run/lpad-daemon.sock` и отдельный сокет
`~/.local/run/lpad-ui.sock` для общения с запущенным UI. Процесс завершается при остановке
сессии или получении сигнала.

## Удаление

Удалите каталог `~/.local/apps/lpad/` и связанные записи автозапуска, созданные `--enable`.
